# Стековый процессор

Структура проекта следует образцу BeVa733/stack_processor:

- `include/calc.h` — общие коды команд и описание программы.
- `asm/include/assem.h` — структуры текста и объявления функций чтения и разбора.
- `asm/src/onegin.cpp` — чтение файла и разделение на строки.
- `asm/src/assem.cpp` — распознавание команд и заполнение массива инструкций.
- `spu/include/spu.h` — состояние процессора и объявления обработчиков.
- `spu/src/spu.cpp` — main, управление ресурсами и цикл выполнения.
- `spu/src/funk.cpp` — обработчики арифметики, вывода и переходов.
- `stack/include/stack.h`, `stack/src/stack.cpp` — библиотека стека.
- `stack/src/main.cpp` — отдельный пример стека.
- `tests/` — примеры входных программ.

## Сборка и запуск

Из корня проекта:

```sh
make
./calc_app
```

Программа читает `program.asm` из текущей папки. `tests/arithmetic.asm` — копия примера на момент переноса.
Отдельный пример стека собирается командой `make stack_test` и запускается как `./stack_test`.

Пока чтение, разбор и выполнение объединены в одном приложении. Отдельные исполняемые ассемблер и процессор, бинарный формат и дизассемблер ещё предстоит реализовать.
